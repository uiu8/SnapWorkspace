# Snap Workspace 0.9.5

本版集中修复智能捕捉、兼容定位和浏览器后台启动之间的边界问题。

## 新增

- 智能捕捉页新增“手动点选窗口”：主窗口会暂时隐藏，左键点选任意顶层窗口即可加入捕捉列表，Esc 或右键取消。
- 手动点选项目使用独立的“手动选取”来源，不受任务栏、托盘和纯后台范围开关影响。

## 修复

- 兼容窗口捕捉优先读取 `WINDOWPLACEMENT` 的正常还原矩形，避免最小化、越界或瞬时标题栏尺寸污染工作区。
- 不再把越界窗口逐边裁剪成 `1×1`；现在保留原尺寸并整体平移回工作区。
- 新捕捉若仍只有异常小的窗口区域会被明确拦截，不再静默保存错误布局。
- 旧版已经保存的极小兼容区域会在恢复时根据当前窗口正常矩形自动修复；无法读取时使用可见安全区域。
- Chrome、Edge、Brave、Vivaldi 和 Opera 的后台角色改用 Chromium 原生 `--no-startup-window` 协议，不再创建后强制隐藏单实例浏览器主窗口。
- Chromium 后台角色不会隐藏用户现有的浏览器窗口；普通前台启动仍可立即创建任务栏窗口。
- 原生 Snap 自动建议同时检查窗口样式，固定对话框不会仅因尺寸够大而误判为原生可吸附窗口。

## 验证

- 覆盖工作区模型、越界几何平移、异常尺寸拦截、旧版 `1×1` 兼容区域自愈和运行时路由回归。
- 在本机 Chrome 上验证：无窗口启动期间没有桌面窗口；随后普通启动在一秒内出现前台窗口，关闭后无隐藏主窗口残留。
