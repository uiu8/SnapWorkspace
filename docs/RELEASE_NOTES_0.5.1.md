# Snap Workspace 0.5.1

This is the final packaged build of the 0.5 capture-role redesign described in `RELEASE_NOTES_0.5.0.md`.

- Native Snap, compatibility-positioned, background and ignored roles remain strictly separated.
- Smart and manual capture use the same compact role picker and clear descriptions.
- Legacy pseudo-Snap captures migrate to compatibility positioning.
- Compatibility positioning and background hide behavior passed actual-window tests.
- The source archive excludes generated UI regression images and build output.
