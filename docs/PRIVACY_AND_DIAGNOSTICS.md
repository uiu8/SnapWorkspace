# 隐私与诊断

Snap Workspace 的诊断数据只写入当前电脑，不自动上传。支持包由用户明确导出；应用身份和完整工作区是两个独立、默认关闭的敏感选项。

## 默认记录什么

启用“记录本地匿名诊断事件”后，事件按天写入：

```text
%LOCALAPPDATA%\SnapWorkspace\diagnostics\snapworkspace-yyyyMMdd.jsonl
```

每条记录包含：

- UTC 时间；
- 级别；
- 事件名；
- Snap Workspace 当前进程 Id；
- 与操作相关的数量、状态、工作区 Id、应用项 Id 或异常类型。

默认事件不记录：

- 工作区名称；
- 应用完整路径；
- 启动参数和工作目录；
- 窗口标题；
- 完整工作区 JSON；
- 文件内容、键盘输入或屏幕截图。

日志写入失败会被吞掉，不允许影响工作区恢复。超过 7 天的 JSONL 文件在后续写入时删除。

## 默认支持包内容

默认导出的 ZIP 包含：

| 文件 | 内容 | 敏感级别 |
|---|---|---|
| `manifest.json` | 应用版本、操作系统、.NET、架构、隐私开关 | 低 |
| `settings-summary.json` | 主题、托盘/启动项状态、规则和收藏数量 | 低 |
| `route3-capability.json` | Shell 路径、版本、哈希、接口与能力结果 | 中 |
| `workspaces-summary.json` | 匿名工作区序号、布局 Id、角色和空槽位数量 | 低 |
| `diagnostics/*.jsonl` | 最近最多 7 个本地事件文件 | 低到中 |

Route 3 能力信息可能暴露 Windows 系统目录和精确系统版本，但不包含用户应用标题。

## 两个敏感选项

### 包含应用路径、启动参数和窗口标题

开启后增加 `application-details.json`，可能包含：

- 工作区 Id 和名称；
- 应用 Id、名称、角色和 Zone；
- 进程路径、AUMID、包身份和窗口类；
- 捕捉标题；
- 启动参数和工作目录；
- 当前窗口 HWND、进程 Id、标题和可见矩形。

这些数据可能暴露用户名、安装目录、正在编辑的文件名、网页标题或私有项目名。只在排查匹配、路径和启动问题时开启。

### 包含完整工作区定义

开启后增加 `workspace-definitions/<id>.json`。完整定义包含应用路径、标题规则、参数和布局，可能足以重建用户的工作环境。只在需要复现数据模型或迁移问题时开启。

两个选项互相独立。可以只导出应用明细，也可以只导出完整工作区定义。

## 推荐的问题报告流程

1. 先导出默认支持包；
2. 打开 ZIP，查看每个 JSON；
3. 如果默认包足够，不要开启敏感内容；
4. 若问题涉及某个应用身份，开启应用明细后重新导出；
5. 若问题涉及迁移、Zone 或字段校验，再开启完整工作区；
6. 发送前删除与问题无关的敏感条目，或使用测试工作区复现；
7. 通过项目指定的私密安全/支持渠道提交。

Snap Workspace 不包含网络上传代码路径。导出只创建本地 ZIP，用户决定是否、如何发送。

## 清理和关闭诊断

- 在设置中关闭“记录本地匿名诊断事件”，停止写入新事件；
- 选择“清除诊断事件”，删除 `diagnostics` 下的 JSONL；
- 该操作不删除工作区、备份、设置、屏蔽规则或角色规则；
- 已经导出的 ZIP 不会被自动删除，需要用户自行管理。

## 本地数据的其他隐私点

`workspaces` 和 `backups` 本身包含应用路径及捕捉标题。即使从不导出支持包，本机其他有权访问当前用户资料的程序仍可能读取这些文件。

建议：

- 不在工作区标题中放密码、令牌或客户机密；
- 启动参数不要保存明文凭据；
- 分享 `.snapworkspace` 前先检查包内 JSON；
- 公开 issue 中不要直接粘贴完整用户路径和窗口标题；
- 企业环境按本地配置文件的备份和访问策略管理 `%LOCALAPPDATA%\SnapWorkspace`。

## 支持包验证覆盖

`SnapWorkspace.App.SmokeTests` 会注入测试路径、标题和工作区名称，验证：

- 默认支持包不出现这些私有值；
- 开启应用明细后按预期出现；
- 开启工作区定义后才包含完整 JSON；
- 轻量托盘宿主不要求加载完整主窗口。

运行：

```powershell
dotnet run --project SnapWorkspace.App.SmokeTests -c Release --no-build
```
